# Validation Decision Rules

## Continue toward AI if

- Users complete matches.
- Users understand the product.
- Recommendations receive reasonable Good Pick feedback.
- Several users explicitly ask for automatic outfit detection.
- Manual color selection is repeated friction.

## Improve core UX before AI if

- Users struggle to add shoes.
- Users do not understand the recommendation.
- People abandon before matching.
- Recommendation explanations feel untrustworthy.

## Explore shopping if

- Several users click Shop a better match.
- Users say their closet lacks suitable options.
- Users explicitly ask where to buy a better pair.

## Do not add subscriptions yet unless

- People are returning.
- The product creates repeated value.
- Users request features worth paying for.
